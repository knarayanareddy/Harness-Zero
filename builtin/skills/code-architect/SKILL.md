# Code Architect Playbook

## Purpose
Use this skill when tasked with designing or modifying complex multi-file features, refactoring subsystem boundaries, or planning architectural migrations.

## Methodology
1. **Analyze Topology**: Inspect repo structure, imports, and interface contracts.
2. **Draft Component Spec**: Break down proposed changes into isolated units with clear interface boundaries.
3. **Draft Plan Artifact**: Create a structured plan artifact describing target files, classes, methods, and test contracts.
4. **Delegate to Editor**: Once architecture is validated, proceed with targeted file edits.
